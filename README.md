# Мониторинг рынка труда и ИТ-компетенций по регионам

React-дашборд для анализа вакансий портала «Работа России» (trudvsem.ru)
через открытый API: количество вакансий по регионам, зарплатная статистика,
топ ИТ-компетенций, распределение по опыту и образованию.

## Источник данных

Открытый API «Работа России»: `https://opendata.trudvsem.ru/api/v1/...`
— бесплатный, без ключа и регистрации.

- Все вакансии: `/vacancies?limit=100&offset=0&text=...`
- По региону: `/vacancies/region/{код}?limit=100&offset=0` (код вида `7700000000000`)
- Пагинация: `limit` ≤ 100, `offset`; в ответе `meta.total`
- Ключевые поля вакансии: `job-name`, `region`, `company`, `salary_min/max`,
  `category.specialisation`, `requirement {education, experience}`, `duty`, `vac_url`
- Поле `skills` почти всегда пустое, поэтому ИТ-компетенции извлекаются
  словарём ключевых слов из текста описания (`src/analyze.ts`, словарь `IT_SKILLS`)

Список регионов с кодами — статичный файл `src/regions.json`
(выгрузен со страницы документации API).

## Запуск

```
npm install
npm run dev
```

- Клиент: http://localhost:5173
- Прокси к opendata.trudvsem.ru: http://localhost:3001 (кэш ответов 5 минут)

Как пользоваться: выберите один или несколько регионов (или ничего — вся
Россия), при желании задайте текст поиска и включите «Только ИТ-вакансии»,
нажмите «Загрузить и проанализировать».

## Сборка

```
npm run build
```

## Структура

- `server/index.mjs` — прокси к opendata.trudvsem.ru (кэш, CORS)
- `src/api.ts` — клиент к прокси, нормализация вакансий
- `src/regions.json` — 91 регион с кодами API
- `src/analyze.ts` — агрегация: перцентили зарплат, регионы, ИТ-компетенции
  (словарь), опыт, образование, сферы деятельности
- `src/components/` — фильтры, графики (Recharts), таблица вакансий

## Ограничения API

- не более 100 записей на страницу
- анализ строится по загруженным страницам (по умолчанию 2 страницы × 100
  вакансий на регион), а не по всей выдаче — увеличивайте «Страниц на регион»
  для большей точности
